# Contributing

## Issues
Use the provided issue templates (`bug_report.yml`, `content_suggestion.yml`, `question.yml`). Incomplete reports will be closed.

## Pull Requests
1. Fork the repository and branch from `main`.
2. Follow the `docs/STYLE_GUIDE.md` strictly.
3. Keep translations (EN, FR, AR) aligned.
4. Fill out the PR template checklist.

## Code of Conduct
This repository follows the Contributor Covenant 2.1. See `CODE_OF_CONDUCT.md`.
