# Security Policy

## Supported Versions
At this time, only the `main` branch and explicitly tagged releases of our software are supported with security updates.

## Reporting a Vulnerability

We take the security of our projects seriously. If you discover a security vulnerability in this repository or any related repository within this organization, please **do not report it via public issues or email**. 

Instead, please report it via GitHub Security Advisories:
1. Navigate to the **Security** tab of the relevant repository.
2. Click on **Advisories**.
3. Click on **Report a vulnerability** (or "Draft a new security advisory").
4. Provide a detailed description of the vulnerability, including steps to reproduce it.

We will acknowledge receipt of your vulnerability report and strive to send you regular updates about our progress. If a fix is accepted, we will coordinate a public disclosure with you.
